ระบุรูป meN- แล้วประกอบคำกริยา

ตอบ2 ช่องต่อข้อ — เลือกรูป meN- ที่ถูกต้องก่อน แล้วค่อยประกอบเป็นคำกริยาตริตานเต็มรูป

📋 คำชี้แจง

  1. โจทย์แต่ละข้อเป็น Kata Dasar ให้ตอบ 2 ช่อง:
    • ช่องที่ 1 "Bentuk meN-" — ระบุรูปหน่วยคำเติมที่ถูกต้อง ได้แก่ mem-, men-, meng-, meny-, menge- หรือ me-
    • ช่องที่ 2 "Kata Kerja Terbitan" — ประกอบรูป meN- ที่เลือกเข้ากับรากศัพท์ให้เป็นคำกริยาที่สมบูรณ์
  2. กรอกคำตอบให้ครบทั้ง 15 ข้อ แล้วกด "ส่งคำตอบ" ด้านล่างสุดเพียงครั้งเดียว เพื่อตรวจทุกข้อพร้อมกัน
  3. ข้อที่ถูกครบทั้งสองช่อง 🟢 จะถูกล็อกไว้ — ข้อที่ยังไม่ถูก 🟡🔴 จะบอกว่าช่องไหนต้องแก้ ให้แก้ไขแล้วกด "ทำอีกครั้ง"
  4. กด "💡 ต้องการคำใบ้?" รายข้อ หรือเปิดแผง "เคล็ดลับ" ด้านล่างก่อนเริ่มทำ — ปุ่ม "↺ ล้างคำตอบ" ใช้เริ่มทำใหม่ได้ตลอดเวลา

เคล็ดลับ: กฎการเปลี่ยนเสียง meN-
เลือก Bentuk meN- จากเสียงแรกของรากศัพท์ก่อน แล้วจึงเติมรากศัพท์ต่อท้าย — กฎเหมือนกับ peN- (คำนาม) ทุกประการ เพียงแค่เปลี่ยน p เป็น m
mem-b, p (p หลุดหาย) — baca → membaca, pukul → memukul
men-d, t, c (t หลุดหาย) — dengar → mendengar, tulis → menulis, cari → mencari
meng-สระ, g, k (k หลุดหาย) — ajar → mengajar, guna → mengguna, kira → mengira
meny-s (s หลุดหาย แทนที่ด้วย ny) — sapu → menyapu, sebut → menyebut
menge-คำพยางค์เดียว (ไม่ว่าจะขึ้นต้นด้วยอะไร) — cat → mengecat, lap → mengelap
me-m, n, l, r, w, y (เสียงนาสิก/ลิ้นสั่นอยู่แล้ว) — masak → memasak

Tahniah! 🎉
